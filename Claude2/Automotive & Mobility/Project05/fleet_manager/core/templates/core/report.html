About Reports
CSV Format

All reports are exported in CSV (Comma Separated Values) format, which can be opened in Microsoft Excel, Google Sheets, or any spreadsheet application for further analysis.

Data Freshness

Reports are generated in real-time based on the latest data in the system. For historical analysis, consider exporting reports regularly and storing them.
