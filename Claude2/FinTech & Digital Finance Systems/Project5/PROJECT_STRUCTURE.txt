Key Features by Module:
========================

Module 1: Financial Behavior Data Collection
├── Models: UserProfile, Transaction
├── Forms: UserProfileForm, TransactionForm
├── Templates: profile_form.html, transaction_form.html, transaction_list.html
└── Views: profile_create, transaction_create, transaction_list

Module 2: Spending Pattern Analysis
├── Logic: Savings rate calculation, spending categorization
├── Views: analyze_profile (partial)
└── File: risk_engine.py (analyze_spending_pattern)

Module 3: AI-Based Risk Profiling Engine
├── Algorithm: Multi-factor risk scoring (0-100)
├── Components: Age (30%), Savings (30%), Stability (25%), Experience (15%)
├── File: risk_engine.py (calculate_risk_score)
└── Views: analyze_profile

Module 4: Risk Tolerance Classification
├── Categories: Conservative (0-40), Moderate (41-70), Aggressive (71-100)
├── File: risk_engine.py (classify_risk_profile)
└── Template: risk_analysis.html (badges, scores)

Module 5: Personalized Financial Insights
├── Logic: Risk-specific recommendations
├── File: risk_engine.py (generate_financial_insights)
└── Template: risk_analysis.html (insights section)

Module 6: Risk vs. Return Visualization
├── Charts: Scatter plot, Doughnut chart
├── Library: Chart.js 4.4.0
├── Views: dashboard, _prepare_chart_data
└── Template: dashboard.html (canvas elements, Chart.js config)

Module 7: Scenario-Based Financial Analysis
├── Calculator: What-if projections
├── Formula: Compound interest with monthly contributions
├── Views: scenario_calculator, calculate_scenario (API)
├── Presets: Bull Market, Bear Market, Recession, Savings Boost
└── Template: scenario_calculator.html (sliders, results)

Module 8: Financial Risk Profiling Reports
├── Output: Printable comprehensive report
├── Views: financial_report
├── Sections: Health Card, Score Breakdown, Insights, Recommendations
└── Template: financial_report.html (print-optimized)

Frontend:

Database Schema:
================

UserProfile (1) ----< (N) Transaction
UserProfile (1) ----< (1) RiskProfile

Fields:
├── UserProfile: name, age, annual_income, employment_status, income_stability,
│                 dependents, investment_experience_years
├── Transaction: date, category, amount, transaction_type, description
└── RiskProfile: risk_score, classification, component_scores, savings_rate,
                  spending_pattern, insights
